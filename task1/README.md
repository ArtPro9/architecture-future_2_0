## Что болит в текущей системе

| Проблема                                           | Как это проявляется в работе                                                                  |
|----------------------------------------------------|-----------------------------------------------------------------------------------------------|
| Данные разрастаются (уже сотни ТБ)                 | Сложные отчеты строятся по полдня, бизнес ждет и нервничает                                   |
| Сценариев работы с данными — невероятное множество | Новый отчет делается неделями, постоянно что-то ломается, регрессии не отследить              |
| Трансформаций — через край                         | Железо задыхается, счета за инфраструктуру растут, скорость падает                            |
| Железо и софт давно устарели                       | Не масштабируемся под рост, новые направления подключаем месяцами, есть риски отказа и утечек |
| Домены слишком связаны между собой                 | Любое изменение — как мина замедленного действия, трогаешь одно — падает другое               |
| SQL Server 2008 — архитектурный долг               | Решения принимаются с опозданием, данные не успевают за рынком                                |
| Нет единой точки доступа к данным                  | Аналитики вручную собирают куски из разных мест, теряется время и качество                    |
| Вопросы ИБ и регуляторики висят в воздухе          | Возможны штрафы, проверки, остановка работы, репутационные потери                             |

## Расстановка приоритетов по матрице Эйзенхауэра

### Влияние на выручку

|          | Срочно делать                                                                                               | Может подождать                                                                                                          |
|----------|-------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------|
| Важно    | Перегруженные трансформации, износившееся железо, древний SQL Server 2008, дыры в ИБ и соответствии законам | Запутанная связность доменов, разнообразие сценариев использования данных, объемы данных, отсутствие центральной витрины |
| Не важно | —                                                                                                           | —                                                                                                                        |

|          | Срочно делать                                         | Может подождать                            |
|----------|-------------------------------------------------------|--------------------------------------------|

| Не важно | —                                                     | Витрина данных, вопросы ИБ и регуляторики  |
